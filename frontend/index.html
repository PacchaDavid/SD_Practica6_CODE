Guía de uso — ¿cómo funciona este dashboard?

Este panel consume la API REST del microservicio Java (Spring Boot) para mostrar el estado de una flota de 3 vehículos simulados (VH-001, VH-002, VH-003).

  • Tarjetas superiores: resumen rápido de vehículos activos, alertas vigentes y vehículos con datos de GPS.
  • Gráficos: velocidad actual de cada vehículo (barras) y proporción de alertas por tipo (dona).
  • Lista de vehículos: haz clic en cualquier vehículo para ver su detalle (último GPS e historial de telemetría).
  • Alertas: registro histórico de alertas de temperatura alta (>4 °C) y nivel bajo de combustible (<20 %).
  • Actualización automática: cada 5 segundos se refrescan todos los paneles.

Endpoints utilizados: /status, /vehicles, /alerts, /vehicle/{id}/gps, /vehicle/{id}/telemetria
